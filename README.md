# ⚒️ The Nerd Foundry

> **A collaborative digital workshop for people who love to learn, create, compete, build, and obsess over interesting things.**

The Nerd Foundry is an all-in-one platform designed for nerds of every variety. Whether you speedsolve a Rubik's Cube, build D&D worlds, design Magic: The Gathering decks, code software, engineer robots, study astronomy, play chess, or disappear into a highly specific rabbit hole at 2 AM, The Nerd Foundry aims to give you a place to explore and build.

---

## 🧩 Current Features

### ⏱️ Cubing

A toolkit for speedcubers and other puzzle competitors.

* Solve timer with scramble generation
* 15-second inspection
* `+2` and `DNF` penalties
* Solve history
* Sessions
* Personal best tracking
* Ao5, Ao12, Ao50, and Ao100 statistics
* Practice blocks
* Cube collection
* Cubing profile
* Competition logbook for tracking real competitions

The Cubing section is designed to eventually support all WCA events.

## 🛠️ Planned Technology Stack

The Nerd Foundry is being built with a focus on keeping infrastructure costs as low as possible.

| Service                 | Purpose                         |
| ----------------------- | ------------------------------- |
| Replit                  | Current development environment |
| GitHub                  | Source code and version control |
| Vercel                  | Website hosting                 |
| Clerk                   | Authentication                  |
| Neon                    | PostgreSQL database             |
| Cloudflare R2           | File and asset storage          |
| The Nerd Foundry Domain | Public website                  |

The long-term goal is to keep infrastructure costs at **$0/month**, with the domain being the only required paid expense until the platform grows enough to require upgrades.

## 🎯 The Goal

The Nerd Foundry is not intended to be another collection of disconnected hobby tools.

The goal is to build a platform where people can:

> **Learn → Practice → Create → Build → Collaborate → Document → Share**

A user might design a robot in the Engineering Lab, write its software in the Coding Lab, simulate it, document the build, collaborate with other users, and share the finished project with the community.

Or they might simply track cube solves.

Both are valid uses of the Foundry. One is arguably less likely to result in a robot uprising.
